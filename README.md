# KelvaniDownloader 0.1.6

Im Erweiterungsmenü Befehl kopieren wählen. Windows-Terminal oder PowerShell öffnen, einfügen und Enter drücken. Der Befehl lädt die geprüften Installationsdateien selbst herunter und installiert oder aktualisiert den lokalen Helfer. Kein entpackter Ordner ist nötig. Danach Erweiterung neu laden und YouTube aktualisieren.

Eine Browsererweiterung plus ein lokaler Windows-Helfer für Medienverarbeitung. Keine zweite Erweiterung. Die quelloffene Browsererweiterung muss beim Laden als entpackte Erweiterung dauerhaft im gewählten Ordner bleiben; Edge installiert keine ZIP-Datei.

Der Helfer behebt einen nicht zugänglichen SSLKEYLOGFILE-Protokollpfad. Alte Helfer werden erkannt; ein offener Tab mit abgelaufenem Erweiterungskontext bietet YouTube neu laden an. Verfügbare Formate hängen vom Video ab; keine DRM-Umgehung oder Anmeldung.

Downloads werden direkt im Downloads-Ordner gespeichert, ohne Kelvani-Unterordner. Im Erweiterungsfenster kann ein YouTube-Videolink eingefuegt werden. Andere Websites werden abgewiesen.
