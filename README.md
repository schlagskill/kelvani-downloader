# KelvaniDownloader 0.1.4

Eine Erweiterung mit kompaktem Downloadmenue direkt unter dem YouTube Button. Keine grosse Dialogbox, kein Produkttitel im Menue.

Alte Downloader Erweiterung deaktivieren, dieses ZIP entpacken, den Hauptordner mit manifest.json laden und INSTALLIEREN.cmd starten. Python wird privat eingerichtet; die Erweiterungs ID wird automatisch erkannt. Danach Erweiterung und YouTube neu laden.

Ein lokales Windows Hilfsprogramm fuer Medienumwandlung bleibt erforderlich. Es ist im gemeinsamen Paket enthalten und keine zweite Browsererweiterung. Anleitung und Grenzen: INSTALLATION.md.

Nach einem Erweiterungsupdate kann ein bereits offener YouTube-Tab seine Verbindung verlieren. In diesem Fall bietet das Menü jetzt direkt YouTube neu laden an. Der Helfer muss dafür nicht erneut installiert werden.

Version 0.1.4 erkennt ältere installierte Helfer und zeigt eine konkrete Aktualisierungsanleitung. Erweiterung aktualisieren, INSTALLIEREN.cmd aus dem aktuellen entpackten Paket ausführen, Erweiterung neu laden und YouTube aktualisieren. Das Update der Erweiterung allein aktualisiert den Windows-Helfer nicht.
